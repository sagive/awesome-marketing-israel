# Contributing to Awesome Marketing Israel 🇮🇱

Thank you for taking the time to contribute! 🎉

This repository aims to be the premier, definitive curated collection of Israel's marketing excellence, SEO resources, MarTech platforms, performance communities, and growth playbooks. We welcome contributions that maintain these high editorial standards.

---

## Guidelines for Inclusion

Before submitting a Pull Request, please ensure your suggested resource meets the following criteria:

1. **Relevance**: 
   - The resource must be directly relevant to the Israeli marketing ecosystem (communities, media, events, agencies) **OR**
   - Built / founded by Israeli entrepreneurs (MarTech tools, platforms, open-source projects).
2. **Quality & Utility**: 
   - We prioritize high-utility resources: reputable platforms, active communities, actionable guides, established podcasts, or widely adopted tools.
   - Promotional fluff, thin agency homepages, or spammy affiliate schemes will be rejected immediately.
3. **Active & Maintained**: 
   - Websites, podcasts, communities, or tools must be currently active (not abandoned).
   - Links must be HTTPS and return a valid 200 HTTP status code.
4. **Format & Tone**:
   - Follow the established formatting style:
     ```markdown
     - [Resource Name](https://example.com) - Short, objective, informative description starting with a capital letter and ending with a period.
     ```
   - Avoid buzzwords, exaggerated marketing hype, and subjective claims (e.g. avoid *"The best SEO tool on earth"* — instead use *"Automated keyword tracking and SERP competitor analysis platform"*).
   - Place your entry in **alphabetical order** within the most appropriate section.

---

## How to Submit a Pull Request

1. **Fork** the repository to your own GitHub account.
2. **Clone** your fork locally:
   ```bash
   git clone https://github.com/your-username/awesome-marketing-israel.git
   cd awesome-marketing-israel
   ```
3. **Create a branch** for your addition:
   ```bash
   git checkout -b add/resource-name
   ```
4. **Edit `README.md`**:
   - Locate the most relevant section.
   - Insert your resource in alphabetical order.
   - Ensure the markdown syntax and link work properly.
5. **Commit** your change with a clear commit message:
   ```bash
   git commit -m "Add Resource Name to SEO & Search Intelligence"
   ```
6. **Push** to your fork:
   ```bash
   git push origin add/resource-name
   ```
7. **Open a Pull Request** against the `main` branch of `sagive/awesome-marketing-israel`.
   - Provide a brief note explaining why this resource is a valuable addition to the Israeli marketing community.
